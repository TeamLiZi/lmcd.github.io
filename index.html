多人游戏

在版本详情里下载 server.jar 后按下面顺序执行
  • 把 server.jar 放进一个空文件夹，用 Java 21 / 25（视版本而定）运行一次生成 eula.txt。
  • 把 eula.txt 里的 eula=false 改成 eula=true，同意 Mojang 最终用户许可协议。
  • 再次运行，默认端口 25565；需要改内存就在 -Xmx 里调整。
java -Xms1G -Xmx2G -jar server.jar nogui
