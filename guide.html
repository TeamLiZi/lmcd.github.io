如何将下载的.json文件导入启动器并启动

本站版本列表里直接提供的的是版本的 .json 文件，它记录了这一版需要哪些 jar、依赖库和资源文件。

使用启动器自带的补全文件功能即可在下载不可用的情况下下载游戏内容。

演示环境

以下为本教程文档使用的演示环境。

操作系统Windows 10 专业版 - 版本号 22H2 - 内部版本 19045.6466
Java 版本Java 21 (21.0.7.0)
Minecraft 版本正式版 26.3
启动器版本Plain Craft Launcher 2 正式版 2.99.0.0 (413.50)
录制时间2026-10-24 19:17
记录工具Windows 步骤记录器
ℹ️
开始前确认：你已从本站下载了对应版本的. json文件 (例如 26.3.json)，并且电脑上已安装 PCL 2。

核心原理

  • 版本 文件夹名 必须和 json 文件名 完全一致（不含扩展名）。
  • .json 文件放进 .minecraft\versions\{版本号}\ 后，PCL 就能在版本列表里发现它并显示在客户端上。
  • 此时只有一个.json文件，缺少游戏本体、材质和依赖库 —— 点「补全文件」即可让 PCL 自动补齐，此补齐功能不在下载功能限制范围内。
本次演示使用：.minecraft\versions\26.3\26.3.json
1

打开 PCL 所在的目录

资源管理器

打开 PCL 的所在目录 —— 也就是包含 .minecraft 的那个目录。若不知道位置，可在 PCL 中任选一个版本 → 版本设置 → 打开游戏文件夹直接跳转。

打开 PCL 的游戏目录
2

进入 .minecraft 文件夹

资源管理器

双击打开 .minecraft。所有版本、资源、模组（负责游戏的内容）都存放在这里。

双击进入 .minecraft
3

在 versions 里新建文件夹

资源管理器

打开 versions 文件夹，在空白处右键，依次点击「新建」→「文件夹」。

① 在空白处右键
② 点击「新建」
③ 点击「文件夹」
4

用.json文件对应版本号给它命名

关键步骤

把新建的文件夹重命名为下载的.json文件所对应的版本号，例如 26.3，按回车确认。这个名字必须和 json 文件名一致。

输入 26.3 后回车
⚠️
必须、绝对要与下载的.json文件版本名一致。例如：下载26.3.json 必须创建名为 26.3 的文件夹。
5

进入刚建好的版本文件夹

资源管理器

在 versions 里双击打开 26.3 文件夹，它现在是空的，接下来要把.json文件放进去。

双击进入 versions\26.3
6

把下载的. json文件存进去

关键步骤

打开浏览器的下载目录，找到 26.3.json，按住拖动到刚打开的 26.3 文件夹空白处松开。

① 在下载目录按住 26.3.json 拖动
② 松开到 26.3 文件夹内
放好后，路径下应当存在文件：.minecraft\versions\26.3\26.3.json
7

确认完整路径

核对

点击资源管理器的地址栏，确认当前路径为游戏目录下的 versions\26.3，且文件夹里已经有 26.3.json。

地址栏显示 …\.minecraft\versions\26.3
8

启动 PCL 2

PCL 2

回到游戏目录，双击 Plain Craft Launcher 2.exe 启动 PCL 2。若 PCL 已在运行，请关闭并重启PCL 2。

双击 Plain Craft Launcher 2.exe
9

点击「版本设置」

PCL 2

确保在 PCL 中选中这个版本（26.3），点击「版本设置」，进入该版本的配置页面。

选中版本后点击「版本设置」
💡
若启动PCL 2后显示的版本非刚刚下载的内容，请在「版本选择」中选择版本。
10

向下滚动页面

PCL 2

在版本设置页面用鼠标滚轮向下滚动，找到「补全文件」按钮所在区域。

滚轮下滑查找补全文件
11

点击「补全文件」，等待自动补齐

最后一步

点击「补全文件」，PCL 会自动下载客户端 jar、依赖库、资源索引，缺少 Java 时也会一并提示安装。补全完成后启动游戏即可。

点击「补全文件」
⏳
补全文件操作开始后，即可在PCL的下载界面看到下载进度，与正常下载游戏无差别，但需等待下载完成。

常见问题

PCL 里看不到我放进去的版本？
99% 是名字没对齐：文件夹名与 json 文件名必须完全相同，且 json 要放在版本文件夹内部，不是直接扔在 versions 根目录。
「补全文件」一直失败或很慢？
在 PCL 设置里把下载源切换为 BMCLAPI，或换个网络环境重试。补全支持断点续传，失败后再点一次通常会继续。
提示缺少 Java / Java 版本不对？
26.x 与 1.21.x 需要 Java 21 或更高（26.x 推荐 Java 25）。可在首页的「运行环境」区获取对应版本。
可以直接下载 jar 吗？
可以。在下载站点开版本「详情」，里面有「下载客户端（.jar）」和「下载服务端（.jar）」，适合手动部署或开服。

打开 HMCL 所在的目录

资源管理器

打开 HMCL 的所在目录 —— 也就是包含 .minecraft 的那个目录。可在 HMCL 设置里查看当前游戏目录位置。

打开 HMCL 的游戏目录
2

进入 .minecraft 文件夹

资源管理器

双击打开 .minecraft，然后进入其中的 versions 文件夹。

双击进入 .minecraft
3

新建文件夹

资源管理器

在 versions 文件夹中「新建文件夹」，这一步和 PCL 教程里右键新建的效果相同，只是入口不一样。

点击顶部「新建文件夹」
4

用版本号命名

关键步骤

将新建的文件夹重命名，输入版本号例如 26.3，按回车确认。

输入 26.3 后回车
⚠️

5

双击进入新建的版本文件夹

资源管理器

在 versions 里双击刚命名的 26.3 文件夹进入，它现在是空的。

双击「新建文件夹」列表项进入
已进入 versions\26.3
6

把下载的.json文件存入

关键步骤

打开浏览器的下载目录，找到 26.3.json，按住拖动到 26.3 文件夹里松开。

① 在下载目录按住 26.3.json 拖动
② 松开到 26.3 文件夹内
放好后，路径下应当存在文件：.minecraft\versions\26.3\26.3.json
7

确认完整路径

核对

点击地址栏确认路径为 …\.minecraft\versions\26.3，并核对文件夹里已有 26.3.json（约 43.9 KB）。

地址栏显示 …\.minecraft\versions\26.3
8

启动 HMCL

HMCL

回到游戏目录，双击 HMCL-3.17.0.362.exe（文件名含版本号，以你下载的为准）启动 HMCL。

双击 HMCL-3.17.0.362.exe
9

在版本列表中找到该版本

HMCL

HMCL 启动后进入主窗口，此时版本列表中应能看到刚放入的 26.3。

HMCL 主窗口 · Hello Minecraft! Launcher
💡
看不到新版本？在 HMCL 的版本列表页点击刷新，或重启 HMCL 让它重新扫描目录。
10

首次启动会弹出「游戏意外退出」——这是正常的

常见现象

此刻文件夹里只有一个 json，还没有 jar 与依赖库。若直接启动，HMCL 会弹出「游戏意外退出」窗口。

缺少游戏文件时的提示
点击「关闭」返回
⚠️
看到这个窗口不代表操作有误，只说明文件还没补齐，需要继续下一步。
11

再次启动游戏

HMCL

关闭提示窗口后回到 HMCL 主窗口。直接再次启动游戏，HMCL会自动补齐文件并启动Minecraft。

重新双击 HMCL 启动
回到 HMCL 主窗口

首次启动报错正常，请在此启动

首次启动会出现报错，请再启动一次：

  • HMCL在第二次启动过程中会自动不起文件
  • 补齐文件时（第二次启动）会耗费略多时间，由于需要下载游戏内容，请耐心等待。
  • 若启动还是失败，请手动点击补齐文件或修改Java版本。
⏳
完成后再次点击启动，即可正常进入游戏。若提示 Java 问题，26.x 需要 Java 21 或更高（推荐 25）。

常见问题

HMCL 里看不到我放进去的版本？
文件夹名与 json 文件名必须完全相同，且 json 要放在版本文件夹内部，不是直接扔在 versions 根目录。刷新列表或重启 HMCL 后再看。
为什么一启动就「游戏意外退出」？
因为只放了 json，缺少 jar 和依赖库。参考上方「下一步」完成补全后再启动。
和 PCL 的流程有什么不同？
前半段（建文件夹、命名、拖 json）几乎一样，只是新建文件夹的入口不同：PCL 用右键菜单，HMCL 用顶部功能区的「新建文件夹」按钮。差别在于补全方式。
可以直接下载 jar 吗？
可以。在下载站点开版本「详情」，里面有「下载客户端（.jar）」和「下载服务端（.jar）」，适合手动部署或开服。
